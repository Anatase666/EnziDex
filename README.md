# Сайт «ЭнзиДекс»

Продуктовый сайт стоматологического геля «ЭнзиДекс» на основе фермента
декстраназы. Три страницы и 404, статический экспорт, без серверной части.

Сайт информационный: форм, заявок, регистрации, аналитики и сбора
персональных данных на нём нет и не предполагается.

## Запуск на своём компьютере

Нужен **Node.js 20 или новее** — на нём собирается проект. Проверить, стоит
ли он уже: откройте PowerShell и выполните `node -v`. Если версия не
показалась, поставьте LTS-сборку с [nodejs.org](https://nodejs.org) или
командой `winget install OpenJS.NodeJS.LTS`, затем **перезапустите VS Code** —
иначе он не увидит новую программу.

### Через VS Code

1. **Открыть проект.** File → Open Folder → выбрать папку
   `C:UsersscrooStorageEnzydex_site`. Именно папку целиком, не
   отдельный файл: иначе не заработают подсказки TypeScript.
2. **Открыть терминал.** Меню Terminal → New Terminal, либо
   <kbd>Ctrl</kbd>+<kbd>`</kbd> (клавиша с буквой Ё). Терминал откроется
   уже в папке проекта.
3. **Поставить зависимости** — один раз, при первом запуске и после
   `git pull`, если менялся `package.json`:

   ```powershell
   npm ci
   ```

   Займёт пару минут и создаст папку `node_modules` — её не нужно ни
   открывать, ни коммитить.

4. **Запустить сайт:**

   ```powershell
   npm run dev
   ```

   В терминале появится строка `Local: http://localhost:3000`. Нажмите на
   неё с зажатым <kbd>Ctrl</kbd> — откроется браузер.

5. **Работать.** Правьте файлы в `content/` — страница в браузере
   обновится сама, перезапускать ничего не нужно.
6. **Остановить** — <kbd>Ctrl</kbd>+<kbd>C</kbd> в терминале.

### Что править

Все тексты лежат в папке `content/`, по файлу на раздел:

| Файл | Что в нём |
|---|---|
| `content/home.ts` | Главная страница |
| `content/product.ts` | Карточка продукта, состав, применение |
| `content/faq.ts` | Вопросы и ответы |
| `content/site.ts` | Название, меню, реквизиты в подвале, страница 404 |

Текст в кавычках — то, что видит посетитель. Строки `TODO_CONTENT` менять
на настоящие значения: на сайте они отображаются как «Требует
корректировки».

⚠️ Не удаляйте строки вида `export const …` целиком — на них ссылаются
страницы, и сайт перестанет собираться. Если раздел нужно убрать,
скажите — я уберу и текст, и вёрстку разом.

### Полезные команды

| Команда | Зачем |
|---|---|
| `npm run dev` | Запустить сайт для работы над ним |
| `npm run check:content` | Показать все незаполненные места |
| `npm run build` | Собрать готовый сайт в папку `out/` |
| `npm run typecheck` | Проверить, не сломано ли что-то в коде |

Готовый сайт из `out/` — обычные HTML-файлы: их можно положить на любой
хостинг, сервер для этого не нужен.

### Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `npm : Имя "npm" не распознано` | Node.js не установлен или VS Code не перезапущен после установки |
| `Error: Cannot find module` | Выполните `npm ci` |
| `Port 3000 is in use` | Сайт уже запущен в другом терминале. Закройте его или выполните `npm run dev -- -p 3001` |
| `Export … doesn't exist in target module` | Из `content/` удалён кусок, который используется страницей. Верните его через Ctrl+Z или напишите мне |

## Стек

Next.js 16 (App Router) · TypeScript strict · Tailwind CSS v4 · статический
экспорт. Без UI-китов: все компоненты свои. Иконки — локальный SVG-набор.
Шрифт Onest через `next/font` — переменный, файлы скачиваются на этапе
сборки и раздаются со своего домена, запроса к Google в рантайме нет.

Зависимостей сверх Next, React и Tailwind — ноль.

## Структура

```
app/           маршруты, метаданные, sitemap, robots, OG-изображение
components/
  layout/      Header, MobileMenu, Footer, Container, Section, Logo
  ui/          Button, Accordion, Disclaimer, RichText, Value, JsonLd
  sections/    по одному компоненту на секцию страницы
  icons/       локальный SVG-набор
content/       все тексты сайта, типизированные
lib/           SEO, разбор ограниченной разметки, вспомогательные функции
docs/          требования, правки заказчика, пробелы в контенте, развёртывание
scripts/       проверка контента, пост-обработка экспорта
```

## Где что менять

- **Тексты** — только в `content/*.ts`. В JSX текста нет; это правило,
  а не привычка: заказчик правит формулировки, не открывая вёрстку.
- **Цвета, типографика, отступы** — блок `@theme` в `app/globals.css`.
  Произвольных hex в компонентах нет.
- **Изображение упаковки** — исходник `docs/reference/product-render.webp`
  (рендер на прозрачном фоне). Чтобы заменить картинку, положите новый файл
  на его место и выполните `npm run images`: скрипт сам обрежет поля,
  нарисует тени, нарежет размеры для разных экранов и обновит сайт.
  Готовые файлы в `public/images/product/` руками не правятся.

## Состояние

Сборка проходит, типизация чистая, все страницы наполнены.

Незаполненными остаются фактические данные, которых нет в материалах:
режим применения, противопоказания, реквизиты и регуляторный статус.
На страницах они видны как **«Требует корректировки»**,
полный список с указанием файла — в `docs/CONTENT-GAPS.md`.
