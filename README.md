# Сайт «ЭнзиДекс»

Продуктовый сайт стоматологического геля «ЭнзиДекс» на основе фермента
декстраназы. Восемь страниц, статический экспорт, без серверной части.

## Быстрый старт

```bash
npm ci
cp .env.example .env.local
npm run dev
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Разработка на `localhost:3000` |
| `npm run build` | Прод-сборка и статический экспорт в `out/` |
| `npm run check:content` | Список незаполненных мест (`TODO_CONTENT`) |
| `npm run typecheck` | `tsc --noEmit` |
| `CONTENT_STRICT=1 npm run build` | Сборка, падающая при любом пробеле в контенте |

## Стек

Next.js 16 (App Router) · TypeScript strict · Tailwind CSS v4 · статический
экспорт. Без UI-китов: все компоненты свои. Иконки — локальный SVG-набор.
Шрифт Onest через `next/font` — файлы скачиваются на этапе сборки и
раздаются со своего домена, запроса к Google в рантайме нет.

Единственная внешняя зависимость сверх Next и Tailwind — отсутствует.

## Структура

```
app/           маршруты, метаданные, sitemap, robots, OG-изображение
components/
  layout/      Header, MobileMenu, Footer, Container, Section, Logo
  ui/          Button, Card, Accordion, поля формы, Disclaimer, RichText
  sections/    по одному компоненту на секцию страницы
  icons/       локальный SVG-набор
content/       все тексты сайта, типизированные
lib/           валидация, отправка заявок, SEO, разбор разметки
docs/          требования, пробелы в контенте, развёртывание
scripts/       проверка контента, пост-обработка экспорта
```

## Где что менять

- **Тексты** — только в `content/*.ts`. В JSX текста нет; это правило,
  а не привычка: заказчик правит формулировки, не открывая вёрстку.
- **Цвета, типографика, отступы** — блок `@theme` в `app/globals.css`.
  Произвольных hex в компонентах нет.
- **Отправка заявок** — `lib/submitLead.ts`, единственная точка. Смена
  транспорта не затрагивает ни один компонент.
