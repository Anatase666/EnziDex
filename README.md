# Сайт «ЭнзиДекс»

Продуктовый сайт стоматологического геля «ЭнзиДекс» на основе фермента
декстраназы. Семь страниц, статический экспорт, без серверной части.

Сайт информационный: форм, заявок, регистрации, аналитики и сбора
персональных данных на нём нет и не предполагается.

## Быстрый старт

```bash
npm ci
cp .env.example .env.local
npm run dev
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Разработка на `localhost:3000` |
| `npm run build` | Прод-сборка и статический экспорт в `out/` |
| `npm run check:content` | Список незаполненных мест (`TODO_CONTENT`) |
| `npm run typecheck` | `tsc --noEmit` |
| `CONTENT_STRICT=1 npm run build` | Сборка, падающая при любом пробеле в контенте |

## Стек

Next.js 16 (App Router) · TypeScript strict · Tailwind CSS v4 · статический
экспорт. Без UI-китов: все компоненты свои. Иконки — локальный SVG-набор.
Шрифт Onest через `next/font` — переменный, файлы скачиваются на этапе
сборки и раздаются со своего домена, запроса к Google в рантайме нет.

Зависимостей сверх Next, React и Tailwind — ноль.

## Структура

```
app/           маршруты, метаданные, sitemap, robots, OG-изображение
components/
  layout/      Header, MobileMenu, Footer, Container, Section, Logo
  ui/          Button, Accordion, Disclaimer, RichText, Value, JsonLd
  sections/    по одному компоненту на секцию страницы
  icons/       локальный SVG-набор
content/       все тексты сайта, типизированные
lib/           SEO, разбор ограниченной разметки, вспомогательные функции
docs/          требования, правки заказчика, пробелы в контенте, развёртывание
scripts/       проверка контента, пост-обработка экспорта
```

## Где что менять

- **Тексты** — только в `content/*.ts`. В JSX текста нет; это правило,
  а не привычка: заказчик правит формулировки, не открывая вёрстку.
- **Цвета, типографика, отступы** — блок `@theme` в `app/globals.css`.
  Произвольных hex в компонентах нет.
- **Объёмная визуализация упаковки** — `components/sections/PackageRender.tsx`.
  Построена по материалам из `docs/reference/`, векторная, весит единицы
  килобайт и не даёт скачка вёрстки.

## Документы

- [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) — исходное техническое задание
- [`docs/CORRECTIONS.md`](docs/CORRECTIONS.md) — правки заказчика, отменяющие
  часть ТЗ: что убрано, что добавлено и что сохранено вопреки буквальному
  чтению правок
- [`docs/CONTENT-GAPS.md`](docs/CONTENT-GAPS.md) — что должен предоставить
  заказчик, с указанием файла и того, что именно блокирует каждый пробел
- [`docs/DEPLOY.md`](docs/DEPLOY.md) — переменные окружения, заголовки
  безопасности для nginx / Netlify / Vercel, особенности GitHub Pages
- [`CLAUDE.md`](CLAUDE.md) — правила работы над проектом

## Состояние

Сборка проходит, типизация чистая, все семь страниц наполнены.

Научная база собрана по отчёту о проделанной работе: происхождение
фермента, направленный мутагенез, кинетика четырёх мутантных форм,
пять лабораторных испытаний с методиками и стадия проекта. Все
результаты получены in vitro и помечены соответственно.

Незаполненными остаются фактические данные, которых нет в материалах:
режим применения, противопоказания, реквизиты, даты и исполнитель
испытаний. На страницах они видны как **«Требует корректировки»**,
полный список с указанием файла — в `docs/CONTENT-GAPS.md`.
